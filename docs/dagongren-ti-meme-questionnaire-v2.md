# 打工人 TI 梗版问卷 v2

> 定位：打工人生态位测试，不是心理诊断。  
> 核心：用热梗角色识别用户在职场系统里的常见生存模式、破防点和关系羁绊。  
> 题量：28 题，约 5-7 分钟完成。

## 1. 对外口径

名称：

- 打工人 TI
- Dagongren Type Indicator
- 副标题：测测你是哪种工位生态位

一句话：

> 不是测你是什么人，是测你在这坨职场生态里通常扮演什么角色。

免责声明：

> 本测试仅供娱乐、自我理解和朋友互相贴脸吐槽。结果不代表固定人格、能力、人品、招聘价值或绩效水平。请勿拿来审判现实同事，除非你们关系真的很好。

## 2. 合理性原则

这套问卷不走“正规人格量表”的严肃路线，但要保持内部自洽：

1. 题目都来自具体职场场景，不问抽象人格。
2. 每个选项同时影响 1-2 个角色分和 1-2 个生态因子。
3. 最终结果看最高角色分，同时读取副标签，避免单题决定命运。
4. 负面角色也要可分享：可以嘴损，但不能让用户觉得被官方判刑。
5. 关系系统独立于角色系统，两个人测完后生成羁绊称号。

## 3. 生态因子

后台用 8 个生态因子，不直接公开完整分数。

| 因子 | 含义 | 高分表现 |
|---|---|---|
| carry | 扛活度 | 活会落到你身上，你也真的会往前推 |
| fish | 摸鱼功力 | 低功耗生存，擅长保护能量 |
| boundary | 边界感 | 知道什么不该接，敢说“不基础” |
| chaos | 搅动度 | 让局面更复杂，或能在混乱中获利 |
| bossy | 领导味 | 没有权也会对齐、推进、画饼、安排 |
| pot | 背锅体质 | 锅容易飞到你身上，或你习惯先兜住 |
| repair | 修复力 | 会补台、安抚、降噪、整理残局 |
| legacy | 屎山关联 | 容易制造、继承、修理历史遗留问题 |

## 5. 结果展示结构

结果页不要只给一个角色，要给三层：

1. 主角色：你最接近的工位生态位。
2. 副标签：你的隐藏属性，例如“低功耗”“背锅体质”“领导味溢出”。
3. 羁绊入口：输入朋友结果，生成你们的关系称号。

示例：

> 你当前更接近：`FISH 摸鱼圣体`  
> 副标签：低功耗生存 / 边界感在线 / 会议过敏  
> 系统备注：你不是没上班，你是在以最小功率维持人类形态。
