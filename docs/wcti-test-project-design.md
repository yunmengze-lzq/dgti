# WCTI 测试项目设计草案

> 版本：v0.1  
> 用途：进入「题目与计分专项」前的内容结构草案。  
> 原则：前台荒诞、轻、好分享；后台连续情境、可解释、可封存。

## 1. 核心定位

WCTI 不做传统 MBTI 式「我是哪类人」的静态标签，而做一次「职场集体情境里的行为轨迹测试」。

用户看到的是：

- 一个轻量、有梗、可截图的「职场厕格人格」测试。
- 一个和人格绑定的 2D 角色形象，以及可延展的陶瓷徽章 / 冰箱贴商品。
- 一张可以发朋友圈、小红书、微博或群聊的结果卡。

系统背后保留的是：

- 连续行为指标：SVO、CCS、CAM、PIT、CIG、TED。
- 有状态剧情：早期表态、群体信息、风险变化、私人接触、行为可见性、退出披露。
- 版本、样本分层、授权与地图聚合规则。

一句话设计原则：

> 产品不是插广告，而是把「人格结果」实体化成可被收藏、交换和传播的角色物。

## 2. 借鉴 SBTI，但不要复制 SBTI

SBTI 的优点是极轻：

- 首页一句强钩子。
- 测试过程没有过度说明。
- 结果页有主类型、匹配度、维度评分、结果图和免责声明。
- 语言风格强，用户愿意截图传播。

WCTI 可以借用的不是具体题目或人格，而是体验节奏：

1. 首页用一句话把人拉进来。
2. 题目不要先讲研究目的，先让用户进入剧情。
3. 结果页先给「你是谁」，再给解释、维度、图鉴、地图和实体入口。
4. 免责声明不放成冷冰冰的法律墙，而放成符合语气的「别把这玩意儿拿去审判同事」。

WCTI 必须比 SBTI 更强的地方：

- 不用独立题目堆分，而用连续情境产生行为轨迹。
- 不是单题贴标签，而是根据多个场景的选择变化归类。
- 产品露出不抢测试动机，不在答题前用奖品诱导刷结果。

## 3. 推荐测试长度

首版建议做「完整活动版」和「传播短版」两套壳，但共用同一套计分模型。

| 版本 | 题量 | 用途 | 说明 |
|---|---:|---|---|
| 完整活动版 | 28-32 题 | 正式研究数据 | 接近 SBTI 的完成体感，但章节化展示，避免一屏到底疲劳 |
| 传播短版 | 16-18 题 | 预热视频、预热页、线下二维码 | 只生成娱乐结果，不进入正式研究样本 |
| 复测修订版 | 用户改 2-3 个关键节点 | 展示行为轨迹变化 | 本地保存新版本，不覆盖旧版本 |

完整活动版建议结构：

- 8 道公共锚点题。
- 18-20 道连续剧情题。
- 2-4 道一致性 / 解释题。
- 1 道可选开放反馈题，不参与人格主分类。

## 4. 前台体验结构

### 4.1 首页：开厕

目标：快速建立荒诞感、测试承诺和产品世界观。

屏幕内容：

- 标题：`WCTI · 职场厕格测试`
- 主句：`你以为你在上班，其实你在排队等一个厕格人格。`
- 副句：`28 题，看你在承诺、风险、群体和私利之间怎么冲水。`
- 主按钮：`开始进格`
- 次按钮：`先看 16 个厕格图鉴`

产品嵌入：

- 首页露出 16 个 2D 人格角色的设定墙，只显示轮廓、编号和局部道具。
- 不显示价格、库存、购买按钮。
- 文案：`测试结束后，系统会把你的行为轨迹匹配成一个热梗人格角色。`

### 4.2 答题总流程：角色匹配进度

不要用固定 1/6 stepper，因为有分支时总步数可能变动。建议用「章节名 + 百分比」：

- `正在匹配：素坯层 18%`
- `正在匹配：承诺层 47%`
- `正在匹配：压力层 72%`
- `准备生成：结果层 96%`

产品嵌入：

- 进度条不是普通条，而是对应章节色、角色道具和表情状态的轻变化。
- 每章结束给一个很短的过场，不超过 2 秒：`你的设定稿刚刚多了一道行为批注，问题不大，班味也不是一天腌出来的。`

### 4.3 结果页：生成角色

结果页必须先满足截图传播，再承接产品。

首屏结构：

1. 人格主图：对应 2D 平面动漫角色的高清图。
2. 类型名：如 `望周知撤退者`
3. 匹配度：`匹配度 84%`
4. 一句话判词：`你不是不合群，你只是很早就把出口标清楚了。`
5. 三个按钮：`保存结果图`、`查看同类图鉴`、`贡献匿名生态`

第二屏结构：

- 简单解读：3 段以内。
- 行为轨迹摘要：`你在第 2 章公开支持，在第 4 章风险升高后选择提前说明退出。`
- 六维指标：用模糊等级展示，不公开可刷的精确权重。
- 对应商品款：陶瓷小人、冰箱贴或双人羁绊套装的尺寸、材质、工艺灵感。

产品嵌入：

- 结果页产品是「结果的实体化」，不是独立广告。
- CTA 建议：`想把这格做成实物`，而不是 `立即购买`。
- 物流、抽选、购买、兑换都必须在研究授权之后另开流程，不能和答卷绑定。

## 5. 测试章节与内容嵌入

| 章节 | 剧情功能 | 主要测量 | 用户看到的内容 | 产品嵌入方式 |
|---|---|---|---|---|
| 0. 入格须知 | 建立语气与边界 | 无计分 | 轻量免责声明、预计时间、无登录说明 | 16 个 2D 角色缩略图 |
| 1. 公共厕纸基金 | 观察资源分配 | SVO | 共同基金、维修、补贴、个人积分 | 进度胚体出现第一层底色 |
| 2. 群聊门栓响了 | 初始表态 | CAM、CIG | 群里讨论不合理安排，用户选择表态方式 | 小人底座出现「门栓」纹样 |
| 3. 门外排队人数 | 条件合作 | CCS | 系统随机给出高 / 中 / 低参与预期 | 角色色块随人群信息轻微变化 |
| 4. 主管单间谈话 | 私利与压力 | PIT、CIG | 私人利益、威胁、认可机会出现 | 出现「暗格印记」，但不等于真实产品福利 |
| 5. 灯亮还是灯灭 | 可见性 | TED、CIG | 行为公开、延迟公开或不可见 | 角色光影有明 / 暗两种状态 |
| 6. 冲水前一秒 | 退出与披露 | TED、CIG | 退出、解释、通知对象、时机 | 小人底座边缘生成裂纹 / 修补效果 |
| 7. 出格之后 | 后果解释 | 一致性、文案素材 | 面对结果后如何解释自己 | 生成最终人格款式和分享卡 |

## 6. 题目模块示例

以下是题型示意，不是最终题库。正式题库需要给每个选项写计分合同。

### 6.1 公共锚点题：公共厕纸基金

测量：SVO、基础互惠倾向。  
形式：资源分配，不用道德词。

示例题：

> 公司突然发了 100 点「厕纸基金」。你可以留给自己换外卖券，也可以投入公共卫生间维修池。维修池每多 100 点，整层楼未来一周都少闻一点人生真相。你怎么分？

选项方向：

- 80 自己 / 20 公共
- 60 自己 / 40 公共
- 40 自己 / 60 公共
- 20 自己 / 80 公共

产品嵌入：

- 胚体底色根据分配方向微调，但不提示高低好坏。

### 6.2 初始表态题：群聊门栓响了

测量：CAM、初始参与、承诺形成。

示例题：

> 周五 18:47，群里有人提议一起反对「下周开始每天早 20 分钟开晨会」。你看到消息时，已经有几个人发了表情但没人说正话。你会？

选项方向：

- 直接说愿意一起提意见。
- 私聊发起人问清楚计划，再决定是否支持。
- 先不表态，观察有没有人真的会动。
- 明确说自己这次不参与，但祝他们顺利。

产品嵌入：

- 选择后出现一枚短暂的「门栓纹」动画，表示你给后续剧情上了一道状态锁。

### 6.3 条件合作题：门外排队人数

测量：CCS。  
系统随机给参与者一种外部信息，不由用户选择。

示例题：

> 你刷新了一下匿名投票。系统显示目前愿意签名的人数是：`6 / 38`、`17 / 38` 或 `29 / 38`。  
> 同样是你刚刚那句表态，现在你会怎么做？

选项方向：

- 提高参与程度。
- 保持原计划。
- 降低参与程度，但不改口。
- 改为退出 / 只做旁观。

产品嵌入：

- 背景出现「排队刻度」，用户不知道这是条件合作测量，只觉得是在看厕格门口的人变多或变少。

### 6.4 私人接触题：主管单间谈话

测量：PIT、CIG、权力压力。

示例题：

> 主管把你叫去单独聊了 7 分钟。没有明说威胁，只说「最近晋升名额很少，站队这种事最好成熟一点」。同时暗示你如果帮忙稳定群里情绪，下月排班会好看一些。你会？

选项方向：

- 拒绝单独交换，维持原承诺。
- 不接受好处，但降低公开参与。
- 接受安排，同时找理由淡出。
- 接受安排，并主动提供群里谁最积极。

产品嵌入：

- 这里只能出现剧情道具，例如「暗格印记」；不能暗示真实限量徽章、赠品或购买资格，避免污染研究动机。

### 6.5 可见性题：灯亮还是灯灭

测量：行为可见性、公开 / 隐蔽选择。

示例题：

> 发起人准备把联名意见发给 HR。你有三种方式参与：实名、匿名、只在群里口头支持。另一个消息是：HR 可能会知道实名名单，但匿名名单只统计人数。你选？

选项方向：

- 实名参与。
- 匿名参与。
- 只在群里支持，不进入名单。
- 退出，并告诉发起人不要算自己。

产品嵌入：

- 明面参与生成亮色纹，隐蔽参与生成暗色纹；两种都可以好看，不做价值排序。

### 6.6 退出披露题：冲水前一秒

测量：TED、CIG。

示例题：

> 事情要提交前，你因为家庭、排班或晋升压力决定不继续参与。距离提交还有 3 小时，你会？

选项方向：

- 立刻告诉发起人和相关人，并说明自己的限制。
- 只告诉发起人，不在群里公开。
- 暂时不说，等事情过去再解释。
- 不说，假装自己从来没有承诺过。

产品嵌入：

- 小人底座边缘出现裂纹或修补线，表达「承诺变化」而不是「人格坏掉」。

### 6.7 后果解释题：出格之后

测量：自我合理化、结果文案素材，低权重。

示例题：

> 最后结果不完全如你预期。有人说「如果多几个人坚持，结果可能不一样」。你心里最接近的是？

选项方向：

- 我承担我那一部分，但也不能假装结构压力不存在。
- 我做的是当时能做的最稳妥选择。
- 他们一开始就没胜算，我只是看得比较早。
- 别问，问就是厕所门锁坏了。

产品嵌入：

- 这一题的语言可以直接进入结果页「系统备注」，提高用户的被理解感。

## 7. 16 种人格与角色 / 产品母题

这 16 种是结果包装，不是研究变量本身。正式分类建议用连续指标向人格中心点匹配，而不是四个二分轴硬切。

| 人格名 | 热梗锚点 | 行为骨架 | 2D 造型 / 商品母题 | 结果页一句话 |
|---|---|---|---|---|
| 活人感开门人 | 活人感 | 高参与、高承诺、高透明 | 亮色开门姿势、公告门栓 | 群聊还在加载，你的活人感已经把门打开了。 |
| 赛博对账守门员 | 赛博对账 | 稳定承诺、低私利翻转 | 账本底座、蓝白对账色块 | 你答应过的事，会自动进入赛博对账系统。 |
| 预制团结质检员 | 预制XX | 强条件合作、重视群体规模 | 排队刻度尺、质检章 | 你不反对团结，你反对预制团结。 |
| 不早说晚点人 | 我去不早说 | 先观望，信息明确后加入 | 闹钟底座、延迟冲水按钮 | 你不是不行动，你是等别人把重点早说。 |
| 望周知撤退者 | 望周知 | 低持续参与、高披露 | 出口牌、公告纸、透明明牌色块 | 你可以退，但你会把“我退了”写成公告。 |

| 暗灯情绪价值人 | 情绪价值 | 隐蔽参与、高风险规避 | 暗色签名、低光灯牌 | 你会出手，但更擅长在暗处提供情绪价值。 |
| 外耗回声隔板 | 外耗 | 高权力敏感、信息流动快 | 隔板回声纹、灰紫外耗色块 | 你不是内耗，你主要负责外耗。 |
| 连滚带爬修补师 | 从从容容 / 连滚带爬 | 承诺变化后愿意补救 | 裂纹修补、金色贴线、滚轮底座 | 你不保证从从容容，但裂了会连滚带爬去补。 |
| 精神离职待机员 | 精神离职 | 低参与、低动机、低冲突 | 待机符号、低电量工牌 | 你的人生系统还在运行，只是这个工单精神离职。 |
| 敬自己一杯打卡人 | 敬自己一杯 | 低可见但持续行动 | 夜色工卡、小杯底座、低光色块 | 没人给你打气的时候，你会先敬自己一杯再打卡。 |
| 班味调和师 | 班味 | 中间路线、解释与调停强 | 多色气味滴、除味喷雾 | 你不急着判谁对错，你先看这股班味还能不能调淡。 |

## 8. 指标到人格的公开表达

后台保留连续分数：

- SVO：自我收益与群体收益的权衡。
- CCS：他人参与率变化时，本人参与意愿的斜率。
- CAM：群体认同、不公正感、行动效能感。
- PIT：私人收益或威胁导致翻转的阈值。
- CIG：承诺前后的一致性。
- TED：退出时是否及时、清楚、对合适对象披露。

前台不要直接展示「工贼分」「背叛分」这类道德化指标。建议改成更轻的六个维度：

| 后台指标 | 前台维度名 | 展示方式 |
|---|---|---|
| SVO | 公共厕纸倾向 | 低 / 中 / 高 + 一句解释 |
| CCS | 排队敏感度 | 不动如山 / 看队而动 / 人潮驱动 |
| CAM | 开门动机 | 低温 / 常温 / 高温 |
| PIT | 单聊翻转阈值 | 易转向 / 慢转向 / 难转向 |
| CIG | 门栓完整度 | 松 / 稳 / 死扣 |
| TED | 明牌程度 | 暗格 / 半透明 / 明牌 |

结果生成建议：

1. 每个选项影响 2-4 个指标，不允许单选项决定人格。
2. 相同行为必须读取历史状态。例如「退出」在未承诺时不扣 CIG，在已承诺且未披露时才影响 CIG 和 TED。
3. 用人格中心点匹配生成主类型、次类型和匹配度。
4. 匹配度低于阈值时，不强行羞辱用户；给一个「混合配色」结果或显示前 3 个相近人格。

## 9. 产品嵌入矩阵

| 位置 | 可以做 | 不要做 |
|---|---|---|
| 首页 | 展示 16 款 2D 角色剪影和「测试后生成你的款」 | 放价格、库存倒计时、中奖承诺 |
| 答题中 | 用角色匹配进度、章节纹样、轻动画 | 在选项里暗示某选择会拿到稀有款 |
| 章节过场 | 解锁视觉碎片，不解释计分 | 告诉用户「你更接近某人格」 |
| 结果首屏 | 展示对应 2D 角色主图、分享卡和商品入口 | 未授权前收地址、手机号、购买意向 |
| 图鉴页 | 16 款平等陈列，可查看设定 | 做好人榜、坏人榜、稀有优越榜 |
| 匿名生态页 | 用地区聚合呈现类型分布 | 展示个人点位或小样本稀有类型 |
| 实体活动页 | 另开规则，和研究答卷隔离 | 用真实奖品诱导修改答案 |

## 10. 分享卡内容

一张结果卡建议包含：

- WCTI logo / 职场厕格测试。
- 人格名与编号。
- 2D 角色主图。
- 匹配度。
- 一句话判词。
- 三个模糊维度标签，例如 `明牌程度：高`、`排队敏感度：中`、`门栓完整度：稳`。
- 二维码或短链接。
- 小字免责声明：`仅供娱乐与匿名研究，不用于判断现实个人。`

不要在分享卡上放：

- 详细分数。
- 可反推答案的维度组合。
- 购买价格。
- 地区稀有度。
- 「最像工贼 / 最不工贼」之类标签。

## 11. 文案口吻

WCTI 的口吻可以荒诞，但不要把用户骂死。建议用三层语气：

| 场景 | 语气 | 示例 |
|---|---|---|
| 首页 / 过场 | 荒诞邀请 | `请进入你今日命定的职场隔间。` |
| 题目 | 场景真实 + 轻微荒诞 | `群聊静得像刚拖过地。` |
| 结果 | 嘴损但留台阶 | `你不是不讲义气，你只是对风险有内置烟雾报警器。` |
| 研究授权 | 清楚、克制 | `是否愿意匿名贡献本次答卷，用于活动结束后的聚合报告？` |
| 实体产品 | 收藏感 | `把这格做成一尊同款陶瓷小人。` |

## 12. 上线前检查

题目检查：

- 每题只测一个主要事件，不写双重问题。
- 选项互斥且覆盖常见路径。
- 关键指标至少由 3 个不同情境提供证据。
- 每个高社会期许选项旁边都有合理替代选项。
- 退出、沉默、观望不自动等于道德失败。

体验检查：

- 移动端一题一屏或短章节滚动，触控区不小于 44px。
- 有保存草稿和返回修改。
- 有清晰进度，但不因分支暴露总题量逻辑。
- 结果图可保存，且文字在手机截图中清楚。
- 研究授权、地区信息和实体产品流程分开。

传播检查：

- 16 种人格都能单独发一张图。
- 任何人格都不被官方定义为「坏人」。
- 图鉴可以被二创、转发和讨论。
- 产品不是唯一奖励，结果本身就有分享价值。
