# 打工人 TI 第二问卷设计

> 版本：v0.1  
> 定位：娱乐型职场模式识别，不是心理诊断、招聘筛选或绩效判断工具。  
> 目标：发掘身边不同的打工人协作模式，让用户获得“原来我不是一个人”的认同感。

## 1. 科学边界

当前 WCTI 原型的 8 道题可以做传播原型，但不能宣称“正规测出一个人的稳定性格特征”。

原因：

1. 题量不足。每个维度只有少量题目支撑，难以估计内部一致性。
2. 维度是原创设定。SVO、CCS、CAM、PIT、CIG、TED 有解释力，但还没有经过样本验证。
3. 类型中心点是人为设定。现在的 16 型是角色包装，不是因子分析或聚类分析自然长出来的类型。
4. 没有信度、效度和常模。无法说明复测是否稳定，也无法说明分数和真实工作行为之间有什么关系。
5. 场景题容易受当日心情、当前工作处境、用户想呈现的形象影响。

所以更稳妥的对外说法是：

> 打工人 TI 测的是“你在常见职场情境中的自我报告式工作模式倾向”，不是你这个人的本质性格，也不用于评价能力、人品或职业价值。

## 2. 产品改名建议

中文名：打工人 TI  
英文缩写：DGTI，Dagongren Type Indicator  
一句话：看看你是哪种打工人模式。

页面免责声明建议：

> 本测试仅供娱乐、自我理解与匿名群体观察。结果描述的是你在职场场景里的常见应对模式，不代表固定人格、心理诊断、职业能力或人品判断。

## 3. 四个连续维度

不要把维度做成“好 / 坏”。每个维度两端都要能被喜欢。

| 维度 | 正向端 | 反向端 | 测什么 |
|---|---|---|---|
| G / D | 群聊供能 Group | 独处回血 Deep | 用户更从协作互动获得能量，还是从独立处理获得能量 |
| J / P | 排程控 Judged | 现场派 Pivot | 用户更依赖计划结构，还是更擅长临场调整 |
| M / T | 明牌边界 Ming | 弹性接锅 Tolerant | 用户更倾向提前说清边界，还是先接住局面再说 |
| C / R | 冲刺顶压 Charge | 降噪修复 Recover | 用户压力下更倾向强推冲刺，还是先降噪、拆分、恢复节奏 |

公开展示时建议不用“高低分”，用一句话：

- G：我靠协作充电。
- D：我靠安静回血。
- J：我需要先把地图画出来。
- P：我能在地图变形时继续走。
- M：我先把边界说清楚。
- T：我先把现场接住再说。
- C：关键时刻我能顶上去。
- R：我会保护可持续输出。

## 5. 答题方式

前 24 题使用 5 点量表：

1. 完全不像我
2. 不太像我
3. 看情况
4. 比较像我
5. 非常像我

第 25-28 题是情境选择题，用来校准类型边界。  
第 29-32 题是质量控制和结果文案题，不直接决定类型。

## 7. 情境校准题

### 25. 周一早上，领导突然插入一个“今天必须看见结果”的任务，你最像：

| 选项 | 文案 | 倾向 |
|---|---|---|
| A | 先拉齐目标、截止时间和谁负责什么，再开始推进。 | G/J/M |
| B | 先接下来救火，边跑边叫人补材料。 | G/P/T/C |
| C | 先确认优先级和边界，避免把旧任务一起拖崩。 | D/J/M/R |
| D | 自己先做一个可见版本，再选择性同步。 | D/P/M/C |

### 26. 同事快崩溃了，来找你帮忙，你最像：

| 选项 | 文案 | 倾向 |
|---|---|---|
| A | 把相关人拉到一起，当场拆问题和边界。 | G/J/M |
| B | 先帮他接住一块，别让事情马上炸掉。 | G/T/C |
| C | 问清楚问题后给方法，但不直接代做。 | D/J/M |
| D | 看自己能量，能帮一小块就帮，不能就推荐别人。 | D/R/M |

### 27. 需求已经改了三次，你最像：

| 选项 | 文案 | 倾向 |
|---|---|---|
| A | 开会重定版本线，不然谁都不知道现在做哪版。 | G/J/M |
| B | 先做出一个当前能看的版本，再倒推规则。 | G/P/C |
| C | 发变更清单和影响范围，让所有人对齐代价。 | D/J/M |
| D | 拆成最小可交付，先保证系统别崩。 | D/P/R |

### 28. 团队气氛很低，大家都不太想说话，你最像：

| 选项 | 文案 | 倾向 |
|---|---|---|
| A | 主动出来主持一下，把话题重新推起来。 | G/C |
| B | 做一个清单或表格，让大家至少知道下一步。 | G/J/R |
| C | 安静补关键漏洞，不一定要在群里刷存在感。 | D/J/C |

## 9. 计分方式

量表题：

- 对应正向端的题目，分数 = 用户选项 - 3。
- 每个维度两端相减，得到 -12 到 +12 的连续分。
- 例：G 题总分 - D 题总分 = G/D 维度分。

类型判定：

- G/D 分数 >= +4，记为 G；<= -4，记为 D。
- J/P 分数 >= +4，记为 J；<= -4，记为 P。
- M/T 分数 >= +4，记为 M；<= -4，记为 T。
- C/R 分数 >= +4，记为 C；<= -4，记为 R。
- -3 到 +3 为混合区。混合区用第 25-28 题校准；仍然接近时，结果页展示“主类型 + 邻近类型”。

结果页不要说“你就是某型”，要说：

> 你当前更接近：GJMR 明牌排程修补师。  
> 邻近模式：GJMC 活人感项目经理、DJMR 边界感后台维护员。

## 10. 正规化路线

如果要逐步接近“正规问卷”，建议分三步：

1. 小样本试测：100-200 人，检查题目是否看得懂、选项分布是否极端。
2. 心理测量检验：每个维度算内部一致性、题目-总分相关、2 周复测稳定性。
3. 效度检查：和工作压力、团队沟通偏好、边界感、自评能量恢复方式等外部量表或行为指标做相关分析。

上线前必须避免：

- 用结果做招聘、绩效、晋升判断。
- 说“科学判定你的性格”。
- 做好人榜、坏人榜、稀有优越榜。
- 展示足以识别公司、部门、小团体的类型分布。

更合适的说法：

> 这是一个有心理测量意识的娱乐型职场模式问卷。它可以帮助用户理解自己和身边人的工作应对模式，但在经过正式信效度验证前，不应被称为科学人格测评。
