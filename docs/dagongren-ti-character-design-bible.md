# 打工人 TI 人物形象设计母版

> 版本：v0.6  
> 用途：给 20 个打工人生态位角色统一 2D 人设、美术风格、道具锚点和商品化方向。  
> 风格：双美术线并存。`portrait` 为日系 2D 低多边形立绘精修，`mbti` 为 MBTI/16Personalities 向几何扁平人格插画；两套都保留，不互相覆盖。

## 1. 总画风

- 角色必须是人形或拟人化职场角色，不直接画真实动物。
- 参考人格测试插画的“干净、明亮、几何块面、角色分组色系”，但所有角色、服装、道具和姿态必须原创。
- 每个角色要有一个一眼能看懂的道具：工牌剑、锅盖盾牌、低血量 UI、PPT 法杖、需求瓶、下班结界等。
- 允许夸张和嘴损，但避免恶心画面。`搅 shit 棍` 和 `屎山继承人` 要用混乱线团、文件山、咖啡旋涡、裂开的 Excel 表达，不画真实排泄物。
- 角色图要适合：结果页主图、图鉴卡片、头像裁切、陶瓷小人商品化。

## 1.0 双美术线

### portrait 日系立绘线

以 `public/assets/dgti/style/dgti-style-anchor-v1.png` 为主参考：日系 2D 低多边形立绘、奶油浅底、透明晶面、高辨识动作和道具。用于结果页主视觉、商品化陶瓷小人、角色收藏卡。

### mbti 几何人格线

以 MBTI/16Personalities 类型插画的视觉语言为主参考：扁平矢量、块面几何脸、短比例四肢、职业化姿态、道具一眼懂。只参考风格语言，不复制任何现有角色、服装、姿势或类型图标。用于页面风格切换、轻量头像、榜单/图鉴备用显示。

mbti 线生成统一遵守：

- 人物比例：头大、身体短、四肢简化，整体更像人格测试角色，不像精细动漫立绘。
- 脸部语言：几何块面脸、点线五官、表情靠眉眼和嘴形表达；不要大眼二次元脸、厚涂皮肤和复杂发丝。
- 色块语言：每个角色 2-3 个主色，衣服和道具大色块清晰；不要高密度碎光、透明披风、复杂魔法特效。
- 动作规则：角色像“人格类型图标”一样站得清楚，动作夸张但轮廓干净，缩略图也能识别。
- 锚点规则：一个主锚点必须放大到最显眼，例如拉链嘴、出厂包装、锅盖盾、PPT 飞剑；副锚点只辅助。
- 背景规则：暖白或浅色纯背景，少量扁平符号即可；不要复杂场景和海报化背景。
- 文案规则：图片里不要出现可读文字，靠表情、姿态、道具讲梗。
- 跑偏判定：如果画面变成细腻动漫美少女、写实 3D、厚涂海报、Q 版萌物、或梗点只能放大才看懂，直接判定为重画。

## 1.0a portrait 线细则

`public/assets/dgti/style/dgti-style-anchor-v1.png` 与 `public/assets/dgti/sheets/dgti-support-lineup-v2.png` 用于 portrait 线，保留之前已经生成和调整过的立绘资产。

- 构图：横向四人分栏，每人占一个浅色竖向色区；不要复杂场景，不要过多背景道具。
- 人物比例：少年/青年职场动漫比例，头身比约 1:6 到 1:7，五官清楚，表情强。
- 服装体系：白衬衫、深色西裤、工牌、少量阵营色外套或功能配件；不要仙侠化、礼服化、魔法学院化。
- 块面语言：明显低多边形切面，高光干净，边缘锐利；不要水彩、厚涂、写实、Q 版。
- 动作规则：每个角色必须有“能做成陶瓷小人的大姿势”，比如挡、冲、举、守、躲、指、扛、搅。
- 锚点规则：一个主锚点最大，两个副锚点辅助；不要把所有梗都塞成小零件。
- 文案规则：图片里不要出现可读文字，靠表情、姿态、道具讲梗。
- 生成规则：每次单角色重画必须引用 `dgti-style-anchor-v1.png` 作为风格参考；如果画面变成厚涂、写实、3D、Q 版、过度精致海报感、脸部同质化或背景信息过密，直接判定为跑偏重画。
- 单人竖版允许从四分栏里独立出来，但必须保留这张锚点的奶油浅底、低多边形透明晶面、清爽阴影、深色职场裤装、强表情和大动作道具。

## 1.1 热梗锚点原则

- 梗要转成“可画的符号”，不要只写成台词。比如“低功耗上班”画成低电量背包、暗掉一半的屏幕和省电姿态。
- 工牌是整个 IP 的核心符号：每个角色都可以有不同形态的工牌，比如工牌剑、发疯工牌、超大工牌、透明工牌、冻结工牌。
- “班味”用灰蓝阴影、褶皱衬衫、工位灯光和咖啡渍表达；“活人感”用暖色、开门姿势和群聊光表达。
- “边界感”用下班结界、锁链光效、静音开关表达；“主体性”用脚下站稳的重心和不被拉走的手势表达。
- “豆包型人格/光速道歉”不要单独做复制梗，吸收到 `AICOWORKER 人机同事`：稳定微笑、柔软姿态、模板回复卡、加载条、被发现也不慌。
- “二牛马/外包牛马”可作为后续副角色，不进入第一批主角；如果商品线扩展，可以做成 `牛马本马` 的迷你分身配件。
- 避免把脏话梗画脏。`shit` 相关角色用文件山、咖啡旋涡、技术债地层、爆炸便签替代。

## 3. 19 个活跃角色人设

### CHOSEN 天选打工人

- 核心梗：活该你能干。
- 姿态：站在一长卷待办清单前，单手把工牌剑举到胸前，像被迫接下主线任务。
- 脸：黑眼圈但眼神发光，表情是“我又懂了”。
- 道具：破光环、工牌剑、待办卷轴、红色未读角标。
- 商品化：主推款，可做发光光环和工牌剑。

### COWHORSE 牛马本马

- 核心梗：嘴上骂，手上做。
- 姿态：弓背往前走，背着像登山包一样的巨大工牌和任务清单。
- 脸：很累，但手没有停。
- 道具：超大工牌、待办清单、咖啡杯、低多边形牛角头箍、牛轭式背包肩架、马鬃感乱发、厚重蹄形工鞋。
- 注意：保留人形打工人，不画真实牛或马；牛角、马鬃和蹄形鞋必须是职场道具化/服装化符号。

### CRISPY 脆皮牛马

- 核心梗：血条很短。
- 姿态：身体像易碎件一样僵住，双手小心护住胸口或肋侧，整个人微微后仰，像再来一个需求就会裂开。
- 脸：长发清瘦男，肩长发或低马尾/狼尾，柔和下垂眼，轻微黑眼圈但脸色干净可爱；不要沿用上一版温柔爱心脸，也不要画成脸色发黑的阴沉病态脸。
- 道具：低血量 UI、全身透明裂壳/手机屏碎裂纹、关节绷带、创可贴、气泡膜围巾、回血奶茶。
- 注意：单人精修时“脆皮”必须第一眼能看出来，主锚点是覆盖身体的透明裂壳和碎裂纹，不再用大爱心护盾做主视觉；爱心只能作为很小的回血 UI 或气泡符号。
- 注意：保留人形职场打工人，不画病号服、医院场景、真实牛马或真实伤口；裂纹要像玻璃/陶瓷/手机屏碎裂，不要血腥。
- 商品化：适合做“易碎裂壳”和低血条底座小摆件。

### FISH 摸鱼圣体

- 核心梗：低功耗生存。
- 姿态：坐在工位椅上，屏幕表面是表格，屏幕角落藏着小窗；身体松弛但眼神清醒。
- 脸：淡定、无辜、系统待机。
- 道具：Excel 皮肤、半透明隐藏小窗、耳机、低功耗电池、鱼尾呆毛、鱼鳍耳机、已下班灵魂小鱼影子。
- 注意：表格伪装必须比小窗更显眼，但游戏小窗要在屏幕内一眼能看见，建议占屏幕约 20%-25%，放在中下或右下，被表格网格半遮住，像“认真工作皮肤”下的小摸鱼。
- 注意：鱼元素要明显但符号化，用呆毛、耳机、屏幕角落鱼图标、小鱼灵魂表达，不把角色画成真实鱼人。
- 商品化：适合做可翻转屏幕小摆件。

### POTMAN 背锅侠

- 核心梗：锅从天降。
- 姿态：举锅盖盾牌挡住飞来的锅。
- 脸：震惊但熟练。
- 道具：锅盖盾牌、飞锅、事故时间线便签。
- 注意：单人精修时必须保留完整头发、锅盖、双脚和飞锅边缘；锅盖盾牌是主锚点，飞锅从上方袭来即可，不要让背景锅太多抢走人物。
- 商品化：锅盖盾牌是强识别点。

### FIREFIGHTER 职场消防员

- 核心梗：哪里炸了哪里有你。
- 姿态：抱灭火器冲进燃烧工单。
- 脸：紧张但有战斗感。
- 道具：灭火器、红色警报条、燃烧工单。
- 商品化：可做动态冲刺姿势。

### TRAITOR 工贼嫌疑人

- 核心梗：偷感打小报告，背后给大家加主线。
- 姿态：外套或文件夹半遮头部，猫着腰踮脚，一边藏在门后或桌边，一边偷偷敲电脑/递 KPI 小纸条。
- 脸：只露出半张脸或一只斜眼，笑容很薄，阴险但喜剧化，像正在暗戳戳同步别人的摸鱼证据。
- 道具：遮头外套/文件夹、半藏小喇叭、袖口 KPI 小纸条、上升箭头便签、过度闪亮的金色工牌、偷偷摸摸的脚尖姿态。
- 注意：必须严格保持正常人体结构，全图只出现两条手臂和两只手；两只手都放在身体前侧且能看见手腕/前臂连接。废弃“背后手拿喇叭”思路，小喇叭或 KPI 小纸条只能挂在腰侧、塞进口袋或放在桌边，绝不能出现第三只手、背后手、漂浮手或重复手指。
- 注意：画得好笑，不要画成现实恶人。

### LEADERCARD 领导体验卡

- 核心梗：没权也爱安排。
- 姿态：年轻打工人像抽到“一日领导体验卡”后突然开启职场武魂真身，前景本人一手拿领导工牌，一手拿激光笔；背后浮现半透明巨大秃头领导武魂，压迫感从身后冒出来。
- 脸：本人方脸强眉骨，自信到欠揍，嘴角上扬，微皱眉，像刚获得临时权力；背后武魂是油亮秃头、严肃眯眼、领导味过浓。
- 道具：领导工牌、激光笔、空白 PPT、小讲台、金色临时领导体验卡吊牌、上升箭头便签、悬浮日程、无字“对齐一下”气泡。
- 注意：主锚点是“秃头领导武魂真身 + 手拿领导工牌”；本人不是正式老板，是被临时权力附体的打工人，所以要好笑、有中二感，不要画成严肃企业高管写真。
- 注意：武魂可以像半透明金色/深紫色背后灵或巨大投影，但不能变成恐怖鬼怪；不出现可读文字；激光笔光线、空白投影板、小讲台和夸张姿态要一眼看出在强行安排别人。
- 商品化：适合做激光笔和 PPT 底座。

### STIRRER 搅 shit 棍

- 核心梗：让事情更有层次。
- 姿态：参考图方向，但气质更坏：少年感男角色双手握住一根很长的搅拌棒，站在混乱旋涡中心，把咖啡旋涡、便签、箭头、流程线一起搅成龙卷；动作轻快但明显是明知故犯。
- 脸：小尖脸，亮眼，眯眼坏笑，嘴角上扬，有点欠揍，不是阳光无辜少年。
- 穿搭：轻便通勤潮流感，短袖衬衫/工牌/运动鞋，橙黑和紫色点缀，有“我就是来搅一下”的坏心眼少年感。
- 道具：长搅拌棒、混乱旋涡、飞散便签、箭头碎片、流程线团、咖啡色低多边形涡流。
- 注意：主锚点是“参考图式少年搅拌棒 + 混乱旋涡 + 坏笑”；不要画真实恶心物，用抽象旋涡表达；搅拌棒要长且醒目，旋涡要围着脚下形成中心；画风必须贴近统一的 2D 低多边形人格图鉴，不要过度复杂插画化。

### SHITMOUNTAIN 屎山继承人

- 核心梗：前任留下，现任继承。
- 姿态：人物被埋在文件山、旧系统、裂开的 Excel 和贴满“前任留下”标签的山里面，只露出半个身体；一只手艰难伸出，另一只手抱着破裂表格或旧系统说明书。
- 脸：长脸、下垂眼，麻木、震惊、被迫继承祖传屎山，像已经看完三代需求变更。
- 道具：文件山、旧系统塔、裂开的 Excel、过期接口线、考古小铲子、便签标签、灰尘层。
- 注意：主锚点是“人被历史遗留山埋住，只露半个身体”；可以出现便签写“前任留下”四字作为梗点，但不要大量可读文字；不要皇冠，不要王座，不要真实脏污。
- 注意：像“技术债地质层”和职场遗产继承，不做恶心写实。

### ALIVE 活人感代表

- 核心梗：群聊活人。

## 5. 通用生成提示词约束

- 2D flat low-poly anime personality illustration.
- Original modern Chinese office satire characters.
- Full-body, clean silhouette, expressive pose, clear prop.
- Off-white background, no frame text, no watermark.
- No 3D render, no ceramic render, no stick figure, no photorealism.
- No real logos, no copyrighted character likeness, no direct 16Personalities costume copying.
- For negative/gross roles, use abstract office symbols, not literal disgusting imagery.
