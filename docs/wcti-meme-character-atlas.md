# WCTI 热梗人物图鉴锚点

> 版本：v0.4  
> 用途：给问卷结果、2D 角色设计、陶瓷小人、冰箱贴和商品页统一命名与视觉 brief。  
> 原则：每个人物必须同时有「热梗名」「行为人格」「2D 造型道具」「商品延展」四层锚点，避免只把梗贴在表面。

## 参考方向

- 当前确认主画风锚点：`public/assets/dgti/style/dgti-style-anchor-v1.png`。后续所有人物重画优先参考这张，不再漂到 3D、简笔、厚涂、写实或过度海报感。
- 16Personalities：低多边形 2D 人格插画、四角色分组、强姿态、稳定色系；只参考视觉语法，不复刻原角色。
- SBTI：短代码、荒诞自嘲、结果卡容易截图。
- 中文热梗：优先使用近年仍能被职场用户看懂的表达，如班味、活人感、赛博对账、预制XX、基础不基础、如何呢又能怎、从从容容/连滚带爬、敬自己一杯。
- 商品延展：每个 2D 角色都要有清晰姿态、手持物和底座概念，方便后续落到 6cm 陶瓷摆件、冰箱贴、徽章和双人羁绊套装。

## 命名规则

1. 名字不要只有梗，要让梗和行为人格相互解释。
2. 不使用现实人物、公司、部门或地域刻板印象。
3. 每个人物都要可爱、可收藏，不做坏人榜。
4. 同一个人物在结果页、图鉴页、商品页和订单页保持同一代码。
5. 商品详情必须展示：人物名、梗锚点、道具锚点、结果代码。

## 设计落地规则

- 角色画风：锁定 `public/assets/dgti/style/dgti-style-anchor-v1.png` 的 2D 平面低多边形动漫人物：奶油浅底、透明晶面、干净轮廓、清爽高光、白衬衫/深色裤装/工牌体系、强动作和大锚点；表情和文案走 SBTI 式荒诞自嘲。
- 商品材质：亮釉、磨砂、半透明、金缮裂纹等只用于商品化差异，不作为前台角色主视觉。
- 四角色色系：行动组偏青绿，承诺组偏金色，观察组偏紫色，修补组偏珊瑚红。
- 道具识别：图鉴小尺寸下也要能看出账本、闹钟、护盾、算盘、灯牌、修补笔、喷雾等关键物。
- 商品页：用户未测试时展示示例款；完成测试后默认选中本命款，并把梗锚点写入订单摘要。
